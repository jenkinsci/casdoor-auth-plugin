The claim of the Casdoor token used as the Jenkins user ID, e.g. name, email, preferred_username, id or tag. Leave it empty to use the Casdoor user name (name), which was the only choice before this setting was added. If the claim is missing or empty for a user, the login fails. Changing it on an existing Jenkins makes the users sign in as new Jenkins users, so their permissions, API tokens and settings have to be set up again.
